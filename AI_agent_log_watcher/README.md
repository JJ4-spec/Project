# Instructions
# Follow these steps to set uo and run the project.

# Step 1:  Install Ollama
# Install Ollama on your system.

# Step 2: Pull a Local Model
# Download the local model you want to use with Ollama.
# ollama pull <model name>
# Replace <model name> with the model you want to use.

# Step 3: Configure the Model
# Open log_watcher_agent.py and update the model name to match the model you pulled in Step 2.

# Step 4: Run log_watcher
# Start the log watcher by running:
# python log_watcher.py
